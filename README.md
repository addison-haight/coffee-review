# coffee-review-app

A React web application for browsing and reviewing coffee beans and local coffee shops. Built as a hands-on React learning project.

## Tech Stack

- **React** (with Hooks)
- **React Router** (`HashRouter` for GitHub Pages compatibility)
- `useState` for local state management

## Features

- Browse coffee bean reviews
- Browse local coffee shops
- Add and delete recipe/review entries
- Multi-page navigation via React Router

---

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v14 or higher recommended)
- npm (comes with Node.js)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/addison-haight/coffee-review-app.git
   cd coffee-review-app
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm start
   ```

The app will open at `http://localhost:3000`.

---

## Deployment

This app is deployed to GitHub Pages. To publish the latest changes:

```bash
git add .
git commit -m "your commit message"
git push
npm run deploy
```
